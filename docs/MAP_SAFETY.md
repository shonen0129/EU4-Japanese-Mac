# 2.1.1 国名描画の安全化

2026-11-15作成。4件の実機クラッシュが共通して通っていた国名描画処理について、次の変更を実装した試験版です。**実ゲームでクラッシュが解消したかは未確認です。**

## 実装した変更

1. 国名の字間調整で、日本語文字の内部バイトが末尾英数字へ混入する不具合を修正しました。文字列へ追加した直後、一時バッファ4バイトを必ず消去します。
2. 国名を大文字化する前に、3バイトの内部表現の残り長さ、NUL、不正な文字番号、サロゲートを検査します。エスケープ表現の後続バイトは大文字化しません。
3. 頂点バッファの容量を、実際に描画する「字間調整後の文字列」から計算します。元の名前だけから見積もる方式を改め、描画本体と同じ「文字情報が存在し、+6オフセットの符号付き幅が正」という条件で数えます。
4. 国名の入力は256文字、表示対象は256個の有効字形、作業文字列は8,192バイトを上限とします。異常な入力や上限超過は一時的な表示用コピーを `?` に置き換えます。元の国名、翻訳ファイル、セーブの名称は書き換えません。
5. CurveTextの文字数計算にも同じ境界検査を使い、不完全な内部表現を数え進めません。
6. 地図フックの書き込み失敗・必要なパターンの欠落時は、部分適用した状態でゲームを進めず、プロセスを終了します。上流のエラー画面から続行できる経路も閉じました。実行時フックはメモリ上の変更であり、この停止でセーブを書き換える処理はありません。
7. 地図フックに対する固定200バイトの最適化走査を使用しません。
8. 国名非表示の診断モードと、修正適用状態の診断表示を追加しました。

不正なフォントポインタ自体をすべて検出する機構ではありません。フォントの拡張領域は上流b5の構成を前提とします。また、他のUI等にあるすべてのデコーダを一括で置き換えたものではありません。

## 導入・使い方

EU4とParadox Launcherを終了し、**2.1.1の `EU4 Japanese for Mac.command` でメニュー1**を実行してください。更新時には新しいソース内容を含む別のキャッシュキーでdylibをビルドするため、古い2.1.0のビルドを誤って再利用しません。メニュー7の補訳更新だけではdylibは更新されません。

```text
1. 日本語化をインストール / 更新
3. 診断のみ
9. 地図の国名を非表示にして更新（クラッシュ切り分け）
10. 地図の国名表示を戻して更新
```

メニュー9は地図上の国名生成を停止します。UIの国名等は日本語のままで、地図から国名が消えることを許容した切り分け用です。メニュー10で通常表示へ戻せます。どちらもゲームを終了してから実行します。通常のメニュー1で更新する際は、直前に選んだ表示モードを維持します。

CLIでは `--install-no-map-names` と `--install-map-names` を使えます。通常の `--install` は表示モードを維持します。

診断に `国名描画の安全化: installed (v1)` が出ることを確認してください。国名非表示の設定はapp内の `Contents/Resources/eu4jp-disable-map-names` に記録し、署名・復元の対象に含めます。アンインストールではこのファイルも削除します。

## 対応確認・失敗時

新しい容量計算フックの命令列が実行ファイル内に一意に存在することを、作業コピー上で変更前に確認します。一致しない場合は実行ファイルを変更せず停止します。実機のSteam EU4 1.37.5.0でこの命令列とレジスタ・フレーム配置を確認しました。EU4 1.37.xでもビルド差で一致しなければ適用を停止します。

この一致だけで、将来の別ビルドに対するすべてのABI互換性を保証するものではありません。推奨の1.37.5で確認してください。

従来と同様にapp全体の作業コピーを作り、`eu4_bak`、LC_LOAD_DYLIB、architecture、署名を検証してから切り替えます。切り替え途中の失敗では、app・MOD・管理状態をトランザクション開始前へ戻します。国名非表示ファイルもappと一緒に復元されます。SIPやGatekeeper全体の設定は変更しません。

## 検証と残る課題

- 実際のフックのアセンブリを使い、混入バグ修正を2,369ケースで検証。
- 境界検査・容量計算を、arm64とx86_64の両方でASan・UBSan付き22,360チェックずつ検証。対象全2,337文字、途中で切れた内部表現、文字番号の範囲超過、長さ制限、固定シードのランダム入力20,000件を含みます。
- 新しい容量計算フックのアセンブリで、文字数の受け渡し、元のLEA命令の再実行、全16個のXMMレジスタ、フラグ、スタック復帰を単独テスト。
- 隔離した模擬appで標準インストーラ23ケースと、国名非表示・通常更新での保持・表示復帰・設定を含むロールバック・診断・フォント維持・アンインストールの7項目を確認。設定ファイルをResourcesへ置いた最終構成で署名検証が成功しています。
- 実ゲームの連続進行、外交、併合、ズーム・地図モード変更、Intel実機のプレイは未検証です。修正済みとしたのは再現した文字列破損と防御処理であり、すべてのクラッシュの解消ではありません。

前回指摘したイベント用フォントの欠損、地図処理の共有カウンタの呼び出し単位への変更、上流全モジュールの書き込み結果監査は別の改善課題として残ります。今回のクラッシュ原因と確定していない変更をまとめて増やさず、国名処理の差を比較できる範囲にしています。

修正後も同じ場所で落ちる場合は、元セーブを保管したうえで、メニュー9の構成でも同じ手順を比較し、新しいクラッシュログと診断ログを採取してください。

## 2.2.0の配布方式

ネイティブ部分は管理リポジトリに同梱したソースからビルドします。上流ソースZIPや配布バイナリを実行時に取得する以前の方式は使いません。日本語MODはdependencies.lock.jsonの承認済み版・SHA256に固定しています。現在の手順はルートREADMEとSECURITY.mdを参照してください。
