# 検証範囲と実機テスト手順

検証日: 2026-11-14、補訳追加と再検証: 2026-11-15。インストーラ自身の検証と、EU4のゲームプレイ検証を区別しています。

## 実行済み

ホストはApple Silicon / macOS 27.3、SIP enabled。Rosettaで実際にx86_64プロセスを実行できることを確認しました。利用者のSteamゲーム、playset、セーブは変更していません。

テスト用のx86_64 Mach-O実行ファイルをClangで作り、`EU4 v1.37.5.0` 等の文字列を含む隔離appに配置しました。実際のeu4dll_mac build 5の配布ZIP・注入ツール・dylib、および公式JPMOD配布ZIPを使用しています。テストではホームディレクトリとゲーム／Launcherのプロセス検出のみを隔離環境向けに置き換えています。失敗注入はテスト用コードだけにあり、配布インストーラに隠しテストオプションや取得先差し替え機構はありません。

初回は実ネットワークでGitHub API → 配布ZIP／dist.v2.json → MOD本体を取得しました。その後の多数のケースは同じ実物ファイルをローカルで再生し、Mach-O注入・otool・lipo・codesign・ファイル交換・復旧はmacOSの本物のツールで実行しました。パッチされた模擬実行ファイルをゲームとして起動するテストではありません。

## 補完2.1.0の検証（2026-11-15）

全143 localisationファイルの126,744キーと、Main 1を重ねた129 GUIファイルを検査しました。本文の残存候補713種と歴史的略号5種すべてをレビューし、本文2,614キーとUI356文言を翻訳しました。変数・入力コマンド等を保護したうえで、翻訳対象の未確認候補は0です。ギリシャ文字・キリル文字等、ラテン文字以外の残存文字群も追加検査しました。

38件の既存ユニット検査に加え、5,416件の検査で以下を確認しました。

- UTF-8 SHA256を既知値、ランダム文字列、2,614件すべての元値で照合。
- 生成した2,614本文と215 UI用キーを、レビュー済みの期待値と全件照合。
- 変数・改行・色・アイコン・国旗指定のトークンを保持。
- 69個のGUIの全文を独立実装の期待結果と照合。コメントやウィジェット名、配置、サイズ等の非表示値は変更しない。
- UTF-8・CP1252・BOMを保持。
- 上流の本文変更、GUI変更、キー不在時には古い差分を適用しない。

9項目のネイティブ検証では、全件のZIP出力、ゲームと公式MODのバイト保持、残存語3例の置換、上流の日本語追加とGUI変更、診断、配置失敗時の復旧、削除と再導入を確認しました。既存の23ケースと中断復旧も2.1.0で再実行しています。

これは静的・隔離環境での検証です。実ゲームの全画面・全イベント・描画幅等の目視確認は未実施です。Main 1・Main 2と補完を同じplaysetで有効化して確認してください。別のUI変更MODとの競合も別途確認が必要です。

## 2.0.1で修正した不具合（2.1.0にも継承）

[BUG_REVIEW.md](BUG_REVIEW.md) に修正5項目と上流b5の未修正点を記録しています。14件の追加単体検査では、重複キー除外、ログ／標準出力失敗への耐性、復旧パスの実体比較とリンク拒否、ロック取得後の状態読み取りを確認しました。

監査用の隔離テストでは、将来のMain 1によるGUI上書き追加、Main 2の別ファイルでの同一キー追加、app交換後の継続的ログ失敗、旧版が残した別表記パスの中断記録を再現し、修正後の結果を確認しました。実際にapp交換直後のログファイルを失わせる検査も行い、元app・MOD・管理記録への内容復元を確認しました。今回の監査用ネイティブ検証は計5項目です。既存の23ケース・補訳9項目・中断復旧4項目も修正版で再実行しています。

上流b5の変換コードを使う独立したASanハーネス（arm64とRosetta上のx86_64）で、短いCP1252文字列のバッファ不足と長い4バイト文字列の上限超過を検出しました。通常の日本語の往復変換は一致、絵文字は `????` に変わることを確認しました。ゲーム内入力の確認結果とは区別してください。

[CHARACTER_SUPPORT.md](CHARACTER_SUPPORT.md) に対象と実装を記載しています。Unicode 18.0.0の常用漢字2,136字を基準に、かな・記号を合わせた2,337字を検査しました。変換はarm64とRosetta上のx86_64でASanを有効にして全字の往復一致を確認しました。「𠮟／叱」の区別、分解濁点のNFC合成、短い特殊文字列、長い入力、欠けた内部エスケープも検査しています。

## 実機受け入れ手順

通常プレイ用セーブへの影響を避けるため、テスト用の新規キャンペーンで確認してください。セーブの退避は利用者側で必要に応じて行い、インストーラはセーブフォルダへアクセスしません。

### 環境と導入

1. Intel MacとApple Silicon Mac + Rosettaのそれぞれを用意します。SIPはenabledのままにします。
2. Steam版EU4 1.37.5を選び、EU4／Launcherを終了してメニュー1を実行します。
3. 診断でEU4版、x86_64、Rosetta、SIP、LC_LOAD_DYLIB、dylib、codesign、Main 1／Main 2の存在を記録します。
4. Steamの別Libraryへ移した場合、空白・日本語を含むフォルダの場合も同じ操作を実行します。複数インストールがあれば `--app` で対象を固定します。
5. 他の利用可能な1.37.xも同様に確認します。非対応版では安全停止することを確認します。無理にゲームファイルを加工して版を偽装しないでください。

### 起動と表示

1. Steamの「プレイ」からParadox Launcherを開きます。
2. 対象playsetでMain 1・Main 2を有効にし、他のUI／翻訳MODを外します。言語はEnglishにします。
3. 起動し、メインメニュー、国家名、UI、ツールチップ、マップ文字、3D文字、長文改行を確認します。
4. 新規ゲームで外交画面と台帳を開き、表示と検索を確認します。中国語拼音検索は日本語環境の必須要件ではありません。

### セーブとゲームプレイ

1. 日本語名で新規保存し、上書き、ロード、別のテストセーブの削除を試します。
2. 数か月を高速進行し、外交・台帳・ツールチップを開き直します。
3. テスト環境で「併合対象に属国があり、その属国が第三国から独立支援されている」状況を作り、併合を確認します。再現環境がなければ未検証と記録します。
4. 併合後も進行・保存・ロードできることを確認します。build 5に回避策が含まれることと、その場の条件で回避が機能したことを分けて記録します。

### 再実行と削除

1. 再度メニュー1を実行し、LCの重複がなく、MOD本体取得が省略されることをログで確認します。
2. Steamで整合性確認または対象版の再取得を行い、再実行でバックアップが新本体へ更新され、注入が戻ることを確認します。
3. メニュー5でSub 1を追加し、実績非対応であることを理解した別テスト環境で動作確認します。メニュー6で削除します。
4. メニュー2で「パッチのみ」を選び、dylibと注入がなくなり、MODが残ることを診断します。
5. 再導入後に「完全削除」を選び、対象3MODの `.mod`／`.zip` がなくなり、再署名が有効であることを確認します。playsetからも外します。
6. 再インストールできることを確認します。

バックアップ欠落やディスク障害等の破壊的な異常テストを通常のゲーム環境で実施する必要はありません。隔離したコピーでのみ検証してください。
