# 日本語補完 2.1.0

今回の対象は、EU4 1.37.5.0の英語localisation 143ファイル、JPMOD Main 2 Release 402、Main 1 Release 24を重ねたGUI 129ファイルです。未処理候補を残さず照合し、本文2,614キーとUI356文言（69ファイル、固有訳215件）へ補完を追加しました。

前版の16項目に加え、既存の日本語文中に残る英単語・接続詞・外国語句、人物名・地名・称号、曲名・音楽パック名、追加コンテンツ名、仮置きの文言も対象にしています。2,614件のうち1,377件はOKボタンを「了解」にするものです。数だけで長文の翻訳量を示すものではありません。

[本文の変更一覧](翻訳一覧.tsv) と [UIの変更一覧](UI翻訳一覧.tsv) に対象キーと日本語を全件掲載しています。既存訳の全文は同梱せず、既存の文章へ加える語句だけを一覧化しています。前版で作成したヴェネツィアの長文訳も維持しています。

## 使い方

- 初めて導入する場合: 更新版 `EU4 Japanese for Mac.command` のメニュー1。
- Main 1・Main 2を導入済みの場合: メニュー7。補完だけを更新し、EU4 appと公式MODを変更しません。
- 補完だけ削除する場合: メニュー8。

Launcherの同じplaysetで **JPMOD Main 1: Fonts and UI**、**JPMOD Main 2: Text**、**JPMOD Mac: Translation Supplement** を有効化してください。ゲーム言語はEnglishです。

## 生成方法

本文はUTF-8 BOM付きの `localisation/replace/zzz_eu4jp_mac_supplement_l_english.yml` へ出力します。UIは対象のGUIファイルを実行時に読み、`text`・`buttonText`・`tooltip`・`hint` の表示値だけを追加した日本語キーへ差し替え、補完MOD内の同じ相対パスへ配置します。ウィジェット名、配置、サイズ、その他の設定を保持します。元のゲーム／公式MODのファイルは編集しません。

配布するのはインストーラと新規訳・差分情報です。既存の日本語文章や他作者のGUI全文を含む生成済みMOD ZIPは配布物に同梱せず、利用者の環境で公式配布ファイルとゲームから生成します。補完単体ZIPも、生成を行う `.command` の配布に変更しました。

上流の本文・GUIが変更された場合はSHA256照合で該当項目をスキップし、古い本文やUIを強制適用しません。上流で追加された日本語訳も優先します。Main 2の全英語localisationファイルでキーの重複を検出し、同じキーが複数定義されている場合は補完しません。Main 1が新たに同名GUIを上書きした場合や、上書き元が変わった場合も該当GUIをスキップします。GUIは検証した作業用コピーから翻訳します。診断とログで適用数・スキップを確認できます。

## 検査結果と範囲

- 本文126,744キーを検査し、変数・制御記号を除いた外国語候補713種と歴史的略号5種すべてに翻訳または保持理由を付けました。
- 今回の対象内では、未確認の残存候補は0です。
- 保持するのは実際のキー名（Ctrl・Shift・Home）、コマンドの `nudge`、日付書式に使う序数接尾辞です。変数、国旗・アイコン指定、URL、ファイルパス、入力コマンド等も機能を保つため変更しません。
- 変数・色指定・改行・アイコンのトークンを全対象で照合します。
- 本文とGUIについて、実行時の生成物を全件比較して検証します。

これは上記バージョンのテキストファイルに対する網羅検査です。ゲーム画面・全イベント・全条件の実機確認は未実施です。実行ファイルに埋め込まれた文章、画像内文字、他のMOD、プレイヤー入力や動的に生成される人名等までを「翻訳済み」とはしていません。人物・文化等のゲームデータを変更するSub 1は引き続き任意で、標準では導入しません。

69個のGUIを重ねるため、別のUI変更MODと同時使用する場合は競合確認が必要です。まず標準のMain 1・Main 2・補完のみで確認してください。

補完は非公式です。原作およびJPMODの素材の権利は各権利者に帰属し、他作者の素材のライセンスを本ソフトのMITへ変更するものではありません。

## 常用漢字フォント補完（2.1.0）

補訳MODに日本語フォントの補完を含めます。[対象文字と動作](CHARACTER_SUPPORT.md) を参照してください。初回は通常版のメニュー1で、日本語拡張dylibとフォント補完を同時に導入します。導入後のメニュー7はappを変えずに再生成し、メニュー8では本文・UI補訳とフォント補完をまとめて削除します。

旧版dylibの環境では補完単体スクリプトは従来の本文・UIのみを更新し、常用漢字の全字対応には通常版メニュー1が必要であることを表示します。フォントを含む生成済みZIPは配布せず、Main 1の既存ファイルとMacの日本語フォントから実行時に生成します。標準構成外のフォントMODとの競合は自動解決しません。
